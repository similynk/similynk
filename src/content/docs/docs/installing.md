---
title: Installing
description: Install Similynk on your Android phone.
---

1. On your Android phone, open **Download Similynk** on the [home page](/#download) and tap the app you want. If it won't install on an older phone, get the 32-bit version from the [releases page](https://github.com/similynk/similynk/releases) instead.
2. Open the downloaded file and allow the install when asked.
3. If Play Protect warns you, tap <kbd>More details</kbd>, then <kbd>Install anyway</kbd>.
4. Open it and tap <kbd>Continue with Google</kbd>.
